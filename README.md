# TextiFox Plagiarism Analysis Engine

## Overview
TextiFox is a Java-based plagiarism detection system developed using Data Structures and Algorithms concepts.

The project analyzes textual similarity using:
- ArrayList
- HashSet
- Queue
- Trie
- Graph
- PriorityQueue
- Recursion + Dynamic Programming

## Features
- Text preprocessing
- Stop-word removal
- HashSet similarity matching
- N-Gram analysis using Queue
- LCS similarity using Recursion + DP
- Trie-based word matching
- Graph representation of document similarity
- Ranking using PriorityQueue
- Java Swing GUI

## Technologies
- Java
- Java Swing
- Java Collections Framework

## DSA Concepts Used
- ArrayList
- LinkedList
- Queue
- Hashing
- Trie
- Graphs
- Heaps / PriorityQueue
- Recursion
- Dynamic Programming
